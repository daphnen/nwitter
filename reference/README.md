# /reference

`prototype.html` — 현재 React 프로토타입을 그대로 굳힌 **정적 스냅샷**입니다.
Next.js 마이그레이션 내내 이 파일을 디자인 기준(source of truth)으로 삼습니다.

- 브라우저로 파일을 바로 열면 됩니다. 동작은 하지 않고 보이기만 합니다.
- `<html data-theme="night">` 로 바꾸면 밤 모드 팔레트를 볼 수 있습니다.
- 색·간격·반경 토큰은 파일 안 `<style>` 의 `:root` 블록에 전부 있습니다.

## 보존해야 하는 것

- 파스텔 그라데이션 배경, 배경의 옅은 발바닥 장식
- 라운드 카드(반경 26px)와 **카드 위로 삐죽 나온 고양이 귀** (`.card::before/::after`)
- 발바닥(🐾) 체크 아이콘, 상단 고양이 얼굴 SVG 헤더
- 시간대별 인사말, "오늘도 수고했어요" 푸터
- 카드별 색 계열: 일정=파랑 / 식사=주황 / 일과=보라 / 목표=초록 / 뉴스=노랑
- 글꼴: 제목·본문 `Jua`, 손글씨 포인트 `Gaegu`

## 스냅샷 다시 만들기

프로토타입을 손볼 일이 생기면:

```bash
npm run build
# build/ 를 정적 서버로 띄운 뒤 스냅샷 스크립트 실행
```

원본 React 코드는 `git log` 의 "흰 고양이 테마 개인 대시보드 구현" 커밋에 있습니다.
